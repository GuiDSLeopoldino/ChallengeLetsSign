# LetsSign backend (NestJS)
- Prod URL: https://letssign-api.abacusai.app ; Swagger at /api-docs and /api. Consumed by native Kotlin Android app.
- PDFs stored as bytea in Postgres (document.pdf, pdfFinal, documentversion.pdf) — no S3.
- Auth: custom global JWT AuthGuard (src/common/auth.ts), @Public/@Roles decorators. /auth/register creates ADMIN; signers created by admin (user.adminId).
- Field coords normalized 0..1, origin top-left. Signer only sees doc after send (DRAFT -> 403).
- Error shape: {statusCode, mensagem, erros[], caminho, timestamp}, all pt-BR.
- tsconfig.build.json must keep incremental:false, declaration:false and exclude prisma (else prod build misses files).
- Seed: run `yarn ts-node prisma/seed.ts` (package.json has no prisma.seed config). admin@letssign.com/Admin@123; ana@ & bruno@letssign.com / Signer@123.
